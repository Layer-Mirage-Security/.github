## 关于我们

Layer Mirage Security 是一个专注安全研究的小型团队。

我们做两件事：一是传统安全的硬骨头 —— 漏洞挖掘、二进制逆向、协议分析；二是 AI 时代刚冒头的新攻击面 —— 提示注入、越狱、Agent 权限体系、模型供应链。

老问题我们熟，新问题我们在学。
